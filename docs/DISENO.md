# Referencia visual

Referencia consultada: https://ingenieriatracker.com/

La comparación de capturas en referencias/ingenieriatracker.png se conserva únicamente como referencia de diseño, no se incluye como recurso de la aplicación. Capturas originales de IngenieríaTracker.

Aplicado en FIning: inicio con accesos por función, cuadrícula de horario semanal y resumen de avance. Se mantiene la identidad blanca y roja. Los datos de horario y avance siguen siendo ficticios y temporales; no se representa un mapa curricular oficial completo.
